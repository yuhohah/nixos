🖥️ Passos para Executar no Desktop (nixos-btw)

1 Puxar as alterações no repositório

No terminal do nixos-btw, atualize o repositório local com as novas definições de rede e serviços:

Bash
cd ~/Configuration/nixos
git pull origin main
2 Configurar os Segredos do Agenix

O OmniRoute e o T3 Code utilizam segredos decriptados via chave SSH (~/.ssh/id_ed25519). Escolha uma das opções abaixo:

Opção Recomendada (Chave própria com Agenix):
  1. Obtenha a chave pública do desktop:
    Bash (Desktop)
    cat ~/.ssh/id_ed25519.pub
  2. Adicione a linha em secrets/secrets.nix na lista users = [ luan-arrow luan-nixos-btw ];
  3. Re-cripte os segredos:
    Bash (Desktop)
    cd ~/Configuration/nixos/secrets
nix run github:ryantm/agenix -- -r
git commit -am "chore: add nixos-btw to agenix recipients"
Opção Rápida (Reutilizar chave do Arrow):
Se preferir não re-criptar os segredos agora, basta copiar a chave privada de ~/.ssh/id_ed25519 do notebook para o mesmo local no desktop.
3 Aplicar a Nova Configuração no Desktop

Compile e ative a configuração no desktop. Isso iniciará o OpenSSH na porta 22 e ativará os serviços em background com lingering (inicialização automática no boot sem precisar de login gráfico):

Bash (Desktop)
cd ~/Configuration/nixos
sudo nixos-rebuild switch --flake .#nixos-btw
4 Migrar o Banco de Dados do OmniRoute (Opcional)

Para não precisar reconectar manualmente seus provedores (Kiro AI, OpenRouter, NVIDIA NIM, Antigravity) no desktop, copie o banco de dados do notebook para o desktop:

Bash (Executar no Notebook Arrow)
# Copia o banco SQLite e configurações já autenticadas
scp -r ~/.local/share/omniroute/ luan@nixos-btw.local:~/.local/share/
5 Confirmar Serviços Ativos no Desktop

Verifique se os serviços do T3 Code e OmniRoute estão rodando perfeitamente:

Bash (Desktop)
systemctl --user status omniroute.service
systemctl --user status t3code.service

💻 Conectando e Utilizando a Partir do Notebook

1. Atualizar o Notebook (Arrow)

Aplique o rebuild no notebook para carregar o alias do zsh e as configurações SSH:

Bash (Notebook)
sudo nixos-rebuild switch --flake .#arrow
2. Abrir o Túnel SSH

Basta rodar no seu terminal:

Bash (Notebook)
ai-tunnel

(Esse comando é um atalho para ssh -N -L 3773:localhost:3773 -L 20128:localhost:20128 luan@nixos-btw.local).

3. Acessar as Interfaces no Navegador

Com o túnel aberto, acesse normalmente no seu navegador no notebook:

🤖 T3 Code Workspace http://localhost:3773 Editor de código e chat de agentes remoto 📊 OmniRoute Dashboard http://localhost:20128/dashboard Monitoramento de cotas, Kiro, NVIDIA e OpenRouter

🛠️ Resolução de Problemas (Troubleshooting)

1. O comando ai-tunnel diz "Could not resolve hostname nixos-btw.local":

Verifique o IP local do desktop rodando ip -br a no desktop. Você pode conectar diretamente pelo IP: ssh -N -L 3773:localhost:3773 -L 20128:localhost:20128 luan@<IP_DO_DESKTOP>.

2. Porta 3773 já em uso no notebook:

Se o T3 Code estiver rodando localmente no notebook também, você pode mapear para outra porta local, por exemplo 3774:localhost:3773, ou parar o serviço local no notebook com systemctl --user stop t3code.service.
